## Описание проекта
Интерактивное консольное приложение на языке Java, демонстрирующее базовые возможности языка: работу с целыми и вещественными числами, побитовые операции, обработку текста, одномерные и многомерные массивы, а также организацию методов и рекурсию. Проект разбит на логические пакеты и снабжён консольным меню.

## Инструкция по сборке

Проект собирается вручную без использования систем автоматизации (Maven/Gradle). 

1. Откройте командную строку (Терминал) в корневой директории проекта.
2. Запустите скрипт автоматической компиляции и сборки JAR-архива:
   ```bash
   build.bat
   ```
   *Скрипт создаст папку `out`, скомпилирует исходный код с помощью `javac` и соберёт исполняемый файл `lab2.jar` на основе манифеста `manifest.mf`.*

## Инструкция по запуску

Для запуска собранного исполняемого JAR-архива выполните в терминале следующую команду:
```bash
java -jar lab2.jar
```

После запуска откроется интерактивное текстовое меню. Введите номер задания (от 1 до 7) для проверки алгоритмов или `0` для выхода из программы.
